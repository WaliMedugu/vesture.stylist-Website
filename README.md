# Vesture — Personal Stylist & Wardrobe App

- **Based on**: Exact UI, format, animations, typography, and assets of `normalisboring.es`.
- **Customization**: 100% Customized text tailored for the **Vesture** outfit & personal stylist application.
- **Local Server Port**: [http://localhost:5155](http://localhost:5155)

## How to Run Locally

```bash
node server.js
```
Then visit `http://localhost:5155`.
